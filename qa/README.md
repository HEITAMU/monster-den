## 0.2.0 实际浏览器验证

实际运行官方 Cocos 3.8.8 的帧循环与 WebGL2 图形管线，使用 DOM 鼠标和 CDP 触摸输入；游戏状态仅用于定位和断言，没有改写状态来获得胜利。

- **完整玩法：** 21 次实际摇杆发射完成五房，最终 4 生命、1065 分、0 救援；每房结束仍可保留敌人。首页、工具卡、结算与工具柜均走真实原生 UI。
- **摇杆边界：** 中心点按、死区内松手、推杆回中、场景起手均不会误发射；鼠标右键和中键不能瞄准或发射。测试坐标来自真实 UI 相机投影至画布的 CSS 坐标。
- **移动输入：** 390×844 / DPR 2 下，第二根手指不能改向；原生取消不发射，之后仍可正常冲撞并撞碎木栏。单独松开第二根手指的分支使用明确标注 `isTrusted: false` 的 DOM TouchEvent 夹具，因为 CDP 无法表达该单独结束动作；其余触摸分支使用 CDP 原生输入。
- **画面：** 主流程 420×780，另检查 360×640 的结算与工具柜，以及 390×844 / DPR 2 的首页、瞄准和冲撞。14 张截图随工作流保存；仓库留存 [首页](webgl/01-home.png)、[首次瞄准](webgl/03-room1-aim.png)、[窝主房间](webgl/08-room5.png)、[胜利结算](webgl/09-victory.png)、[移动端瞄准](webgl/13-mobile-aim.png)、[移动端冲撞](webgl/14-mobile-shot.png)。已复看首页、瞄准、移动端、窝主与短屏结算，没有发现阻挡本次试玩的视觉问题；这不是手机实测结论。
- **声音与恢复：** 营地、探索、窝主三首实际音乐资源已解码，AudioContext 为运行状态，场景音乐调度与换曲缓存通过；实际页面刷新后可重开胜利结算且不重复发基础收益。未配置广告时不给奖励且恢复暂停，没有播放真实广告。

### 精确分类的 `touchcancel` 诊断

报告的 `knownDiagnostics` 保留 1 条 Cocos 3.8.8 诊断：官方触摸适配器对不可取消的原生 `touchcancel` 调用 `preventDefault()`，Chromium 忽略这次无效调用。该条目保留原始错误级别、来源、CDP 触发方式与事件数据，没有删除或冒充为零控制台输出。

例外只接受同源官方引擎、完整一致的消息与限定次数，还必须同时验证事件不可取消、瞄准已清除、取消没有发射、随后触摸能够发射并撞碎木栏。其他运行、着色器、资源或控制台错误仍导致检查失败。本次报告的未分类错误、一般警告和失败请求均为空。

## 0.2.0 本地集成检查

检查加载项目中的 `GameMain.ts`、玩法核心、平台适配、模型库、实际 `Boot.scene` 和两份模型 JSON。TypeScript 仅转换为测试宿主可执行的 CommonJS；JSDOM 和 Canvas 2D 提供宿主环境，图形后端是官方 Cocos 3.8.8 的 **EmptyDevice**。类型检查针对项目脚本，未安装的引擎原生平台 SDK 类型包在报告中单列，不计为已验证的原生构建。

五房路线使用底部固定摇杆，经 DOM 鼠标事件、Cocos 输入分发和实际控制器发射 21 次，房间切换通过工具卡回调完成。没有传送到出口或直接写入胜利状态，每个房间结束时仍有存活敌人。EmptyDevice 无法投影渲染相机，因此鼠标坐标明确采用实际摇杆 UI 节点位置与 Cocos 视口缩放计算；这不是浏览器像素坐标验证。

本轮结果包括：

- 中心点按、死区内松手、推杆后回中取消均不发射；从场景起手拖入摇杆不取得控制权；鼠标右键和中键不能瞄准或发射。
- 首页展示角色与局内角色的激活状态正确切换；实际输入发射能撞碎木栏，并经过移动、敌人行动、重新瞄准阶段。
- 累计初始化 425 个运行时 Mesh，场景销毁后未调用销毁生命周期的 Mesh 数为 0。计数包装仍执行引擎原来的初始化与销毁逻辑。
- 未配置广告时不发奖励且恢复暂停；旧局测试凭证不改变当前钱包或快照，也不会被标记为已应用。
- 已结算胜利重开不重复发基础收益；未结算失败可重开；损坏的内层快照被清理并回到首页，之后可开始新局。
- 网页存档、前后台事件和组件销毁均经过检查。错误恢复和失败终局的额外分支使用明确的测试数据，独立于自然通关路线。

1804 是固定步进执行的引擎帧数，不是手机帧率。EmptyDevice 不输出游戏像素、不编译 GPU 着色器，也没有可用音频后端；模型加载和资源释放记录不能替代画面、真实 GPU 内存或人耳试听检查。

## 0.2.0 核心节奏测量

测量环境为 Node.js 24.22.3，以 120 Hz 时间步输入 `GameModel.step()`，在 100 × 100 的无障碍房间向同一方向发射，并保留远处守卫的敌人回合，计时至下次可瞄准。秒数是送入核心的时间步累计，不是 CPU 耗时、渲染帧率或手机秒表测量。

| 发射力度 | 0.1.1 动作周期 | 0.2.0 动作周期 |
| --- | ---: | ---: |
| 3% | 2.63 秒 | 1.01 秒 |
| 11% | 2.88 秒 | 1.25 秒 |
| 50% | 3.51 秒 | 1.84 秒 |
| 100% | 3.92 秒 | 2.16 秒 |

最低发射速度由 1.9 降至 0.55，最高保持 12.8；主体和敌人行动使用 1.5 倍节奏，低速尾段渐进至 3 倍，抓停或回旋尚可用时保留前 0.45 秒正常节奏。轻推和中等力度距离变短，满力度无碰撞距离仍约为 9.305 模型单位。

23 项核心测试覆盖瞄准与真实落点一致、不同帧间隔的状态和事件一致、加速小数余量存取、旧快照兼容，以及在 3%、11%、50%、100% 力度下发射 0.5 秒后仍能触发抓停和回旋。五房核心路线为 21 发、4 生命、1065 分、无救援，累计模拟时间约 28.51 秒，不含瞄准、读提示或选工具时间。这些结果不判断真人拇指是否舒适。

## 复现

提供官方 `cocos-engine` 3.8.8 源码目录及其构建依赖后运行：

```sh
COCOS_ENGINE_SOURCE=/path/to/cocos-engine node tools/check-types.cjs
COCOS_ENGINE_SOURCE=/path/to/cocos-engine node tools/check-game-headless.cjs
COCOS_ENGINE_SOURCE=/path/to/cocos-engine npm run build:web
```

EmptyDevice 检查需要已有的 `@cocos/ccbuild`、`typescript`、`jsdom` 和 `@napi-rs/canvas`；脚本不会自行下载依赖或改写引擎源码。

在可启动 Chromium 的环境中运行实际浏览器检查：

```sh
npm run check:web -- https://your-preview.example/
```

不传 URL 时，脚本服务本地 `web/`。结果写入 `.build/game-browser/`；显式设置 `COCOS_SOFTWARE_GL=1` 使用软件 WebGL，报告记录这一条件。工作流为 [browser.yml](../.github/workflows/browser.yml)，本轮已通过的运行与产物见本页开头。工作流产物默认保留 14 天，报告与必要截图应随仓库保存。
