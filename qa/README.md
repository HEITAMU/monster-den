### 完整入口检查如何运行

测试加载未经改写的 `GameMain.ts`、玩法核心、平台适配和模型库代码，以及实际 `Boot.scene` 和两份模型 JSON。TypeScript 仅转换为可在测试宿主执行的 CommonJS。宿主提供 JSDOM 和 Canvas 2D 环境，图形后端是官方 Cocos 3.8.8 的 **EmptyDevice**。

五房通关使用测试手册中的固定 21 发路线，每次发射都通过 DOM 鼠标事件、Cocos 输入分发和 GameMain 拖拽逻辑，所有拖拽力度至少为 11%。房间切换通过实际工具卡回调完成；没有将玩家传送到出口，也没有直接写入胜利状态。每个房间结束时仍有存活敌人。

3298 是固定步进执行的引擎帧数，**不代表测得了手机帧率或加载性能**。测试证明这条确定路线能够通过当前集成代码，不证明新玩家手感、长期耐玩程度或关卡平衡已达到发行标准。

- 检查中累计初始化了 307 个运行时 Mesh。场景销毁后，记录中未调用销毁生命周期的 Mesh 数为 0。计数包装器仍执行引擎原来的 `initialize` 和 `destroy`；这验证资源所有权与释放调用，尚未测量真实 GPU 显存回收量。

## 实际浏览器验证

本次通过提交为 [`26c5d48`](https://github.com/HEITAMU/monster-den/commit/26c5d48b3de085a892852f5312840c597350230d)，[工作流 44442569356](https://github.com/HEITAMU/monster-den/actions/runs/44442569356) 总结果为 `success`。对应报告保留实际环境、完整路线和 14 个截图检查点；本仓库保留其中四张未经加工的实际截图：[首页](webgl/01-home.png)、[首次瞄准](webgl/03-room1-aim.png)、[窝主房间](webgl/08-room5.png)、[胜利结算](webgl/09-victory.png)。本轮后续提交仅补充文档与证据，不修改被测游戏代码或运行资源。

浏览器检查由 GitHub Actions 在独立 Chromium 中执行，使用 **WebGL2 / ANGLE SwiftShader 软件驱动**，不是 EmptyDevice。它执行完整五房路线，生成实际游戏画面，并检查绘制调用、着色器错误、半透明材质混合与深度写入状态。软件驱动能验证这套着色器的实际编译和输出，不能覆盖手机硬件驱动差异。

覆盖内容包括：

- 21 次 DOM 鼠标拖拽自然通关；工具卡与首页、结算按钮走实际原生 UI。
- 主画面 420×780、短竖屏 360×640、移动端模拟 390×844 / DPR 2；保存首页、各房间、瞄准、结算与工具柜截图。
- CDP 多指输入验证第二根手指不能改变瞄准；真实取消事件不发射，取消后仍能再次拖拽发射。CDP 不能表达单独结束次要手指，因此这一分支采用明确标记 `isTrusted: false` 的 DOM TouchEvent 测试事件，仍经过 canvas、Cocos 和控制器的完整事件路径。
- 三首实际 MP3 解码、AudioContext 运行、场景音乐播放状态与换曲缓存；这不包含人耳试听结论。
- 真实页面刷新后重开已结算胜利，钱包不重复增加；未配置广告时不发奖励且解除暂停。

首次实际截图暴露的两处渲染问题已修正：线性色值缺少显示转换使模型偏暗；在基础 Material 上调用无效的状态覆盖使半透明提示变为实心色块。对应修正同时写入预览效果与 Creator 资产生成流程。

浏览器报告的 `knownDiagnostics` 单独保留一个已核查的 Cocos 3.8.8 提示：官方触摸适配器对不可取消的原生 `touchcancel` 调用 `preventDefault()`，Chromium 提示忽略这次调用。例外只匹配测试主动取消时、同源官方引擎、完整一致的消息且最多一次；还必须验证原生事件不可取消、瞄准已清除、没有误发射、下一次触摸正常撞碎木栏，才接受该诊断。它没有被删掉或冒充为零控制台输出，其他运行、着色器和资源错误仍然使检查失败。

## 复现

提供官方 `cocos-engine` 3.8.8 源码目录及其可用构建依赖后运行：

```sh
COCOS_ENGINE_SOURCE=/path/to/cocos-engine node tools/check-types.cjs
COCOS_ENGINE_SOURCE=/path/to/cocos-engine node tools/check-game-headless.cjs
COCOS_ENGINE_SOURCE=/path/to/cocos-engine npm run build:web
```

EmptyDevice 检查需要可用的 `@cocos/ccbuild`、`typescript`、`jsdom` 和 `@napi-rs/canvas`。脚本使用已有安装，不会自行下载依赖或改写官方引擎源码。

真实浏览器检查脚本已经提供，需要能够启动 Chromium 的环境：

```sh
npm run check:web -- https://your-preview.example/
```

不传 URL 时，脚本服务本地 `web/`。结果与 14 张实际截图写入 `.build/game-browser/`。需要软件 WebGL 的环境可显式设置 `COCOS_SOFTWARE_GL=1`，报告会记下这一条件。工作流定义为 [browser.yml](../.github/workflows/browser.yml)；工作流产物有保留期限，随仓库保存的报告与选取的截图用于长期复核。
