# 美术与音效说明

- `assets/resources/art/forest.jpg`：生成式手绘森林原画，经裁切优化。
- `assets/resources/art/hero-*.png`：角色多视角原画裁切，抠图成 RGBA。
- `assets/resources/art/hunter|mantis|moth|lampseed|portal|refill|camp|pulse.png`：原创概念单元拆分。
- `glow.png`、`vignette.png`、`shadow.png`：由 `tools/make_fx.py` 生成的辅助特效纹理。
- `assets/resources/sound/*.mp3`：由 `tools/make_audio.py` 确定性合成的原创配乐和短音效，未使用商业样本或受版权保护的现成配乐。

**注意：** 这批图作为可交互工程的初始美术资源，不等于已经由画师完成所有动作和场景级别的最终验收。
