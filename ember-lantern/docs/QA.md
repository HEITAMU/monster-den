## 浏览器冒烟测试

`npm run check:browser` 可在配有 `python playwright` 和 `chromium` 的环境中运行；脚本用内嵌资源注入绕过本沙盒不允许本地 HTTP 导航的限制，不能代表正常网页部署成功。它检查手机 390×844 适配、按钮、游戏规则到结算完整流程，以及页面 JS 异常，并在项目父级导出各画面截图。音频使用无声替代，不能验收音质。
