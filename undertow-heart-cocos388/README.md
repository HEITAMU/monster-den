# 逆潮之心 · Undertow Heart

原创**3D竖屏动作+环境反击+局内随机升级**微信小游戏工程，目标引擎 **Cocos Creator 3.8.8**。

## 玩法

**按住**吸附逼近灯塔的敌人，**拖动**瞄准反击方向，**松手**把敌人当成弹药射向别的敌人。连锁爆炸积累更高分数；蓄力超过2.7秒将过载伤及自身，必须在风险与收益之间选择。四波关卡包含三次三选一能力进化、4种不同生物（含Boss）和可结算的胜负状态。

首局约2分钟；死亡后可通过**自愿观看真实微信激励视频**复活一次，胜利后可自愿观看换取双倍海晶。没有真实广告位 ID 时会显示“尚未配置”，**不会虚假发奖**。使用本地持久化的海晶、最高分和永久等级（20级封顶）。

## 启动与调试

1. 在 Cocos Dashboard 中用 **Cocos Creator 3.8.8** 打开这个目录。
2. 打开 `assets/Scenes/Main.scene`，点击编辑器“预览”。动态构造 3D 场景，不需要贴图素材下载。
3. 使用 `npm test`（本机有 TypeScript tsc 时）运行纯逻辑测试。
4. 在 `assets/Scripts/Ads.ts` 将 `WECHAT_REWARDED_UNIT_ID` 替换成后台申请的真实 `adunit-...`。
5. Cocos 构建发布选择“微信小游戏”，设置正式 AppID 和竖屏模式，微信开发者工具导入构建目录；实机验收并备案后再提交审核。

## 美术原则与当前完成度

场景采用真实三维曲面网格和法线，基于雕塑化的潮心、浮游海鳐、骨刺生物、拟态生物、巨骸和深海珊瑚遗迹，拥有独立鳍肢、触手等部件动画，不用平面角色图片或简单形状替身。UI的按钮背景使用二维绘制。

**尚不满足商业成品级美术标准**：目前是原创程序化曲面雕塑，没有高精度手工角色、完整骨骼动画、动画镜头演出或移动端后处理特效。该环境未安装 Cocos Creator 编辑器，**没有完成编辑器构建，也没有微信真机测试**。因此这是“可供导入的完整游戏逻辑与场景工程”，不是已通过微信审核的成品，不应宣称已经上架。
